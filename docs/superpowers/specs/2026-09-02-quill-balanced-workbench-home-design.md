# Quill 平衡工作台首页设计

**状态：设计已确认，待实现**  
**日期：2026-09-02**

## 目标

修正过度收紧的“后台表单感”，在 task-first 控制台与足够的产品呼吸感之间取得平衡。首页保持 theme 对齐，不回退到杂志式 Hero 或彩色营销卡片。

## 结构

- 顶部保留简洁 `Quill / 新建任务` 上下文行，使用比当前控制台版更舒展、但不等同 Hero 的下方间距。
- 标题为中等尺度的 `把任务交给 Quill`，使用 `font-serif`、`text-3xl` 至 `text-4xl`；其下一行仅说明“描述目标并附上资料，即可开始处理”。
- 任务输入器置于标题之后，以现有 theme Card/token 样式呈现，保持其为首屏中心。
- 常见任务区和 01—04 索引卡片保持不变；其与输入器间采用舒适而克制的间距。

## 约束

- 仅修改新任务空态布局和文案；不改变 API、数据、快捷入口、表单、研究模式或键盘逻辑。
- 所有视觉属性继续由 `@zmzai/theme` token 与现有 `Card` 提供；不使用 inline color、渐变或图片资产。
- 窄屏沿用同一信息顺序，标题自然换行且无横向溢出。

## 验证

运行 `pnpm typecheck` 与 `pnpm lint`；检查 1440px 和 390px 下任务输入器仍位于首屏内，且本次空态无硬编码色。
