# Quill 工具控制台首页设计

**状态：设计已确认，待实现**  
**日期：2026-09-02**

## 目标

将 `/quill` 首页从杂志式、叙事型 Hero 改为任务优先的工具控制台。用户进入后应立即看到任务输入器和常见任务，而不是先阅读产品宣言。

## 页面结构

1. 保留现有 `Quill / 新建任务` 顶部上下文行，但把大间距收紧为普通工具栏节奏。
2. 用左对齐的简短 `新建任务` 标题和一行辅助说明替代眼眉、超大衬线标题及营销描述。
3. 任务简报紧随标题；保留现有输入、附件、研究模式、工作区状态和提交逻辑。
4. 常见任务区紧随输入器，沿用已对齐 theme 的 01—04 索引卡片。
5. 保留低权重的“从问题到交付”说明行；不新增最近任务、数据面板或接口。

## Theme 与交互

- 只使用现有 `@zmzai/theme` token 及 `Card`；不增加内联颜色、图像、渐变或营销装饰。
- 标题使用工具界面现有的 `font-serif text-2xl` 级别，而非 Hero 级字号；正文使用 `text-ink-2`。
- 所有快捷入口、附件、研究模式、提交禁用与 Enter/Shift+Enter 行为不变。
- 响应式下不改变信息顺序，并保持无水平溢出。

## 验证

运行 `pnpm typecheck` 和 `pnpm lint`，检查桌面与 390px 宽视口下输入器位于首屏主要位置；确认空态、四项快捷任务与研究模式预填行为可用。
